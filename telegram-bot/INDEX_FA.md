## سریع‌ترین مسیر (۱۰ دقیقه)

```bash
# ۱. MySQL را آماده کنید
mysql -u root -p
# CREATE DATABASE vpn_bot_db CHARACTER SET utf8mb4;
# CREATE USER 'bot_user'@'localhost' IDENTIFIED BY 'pass';
# GRANT ALL PRIVILEGES ON vpn_bot_db.* TO 'bot_user'@'localhost';
# FLUSH PRIVILEGES;
# EXIT;

# ۲. پروژه را تنظیم کنید
cd fredobot/telegram-bot
nano .env
# BOT_TOKEN=...
# MYSQL_PASSWORD=pass
# ADMIN_IDS=...

# ۳. راه‌اندازی کنید
npm install
npm run setup-db
npm start
```
